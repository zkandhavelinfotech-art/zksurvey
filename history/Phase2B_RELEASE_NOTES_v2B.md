# ZKSurvey v2B — Complete Static Product Prototype

## Customer-facing purpose
This build is designed for the first FMCG dishwash customer. It demonstrates how a pre-launch research program can connect directly to future customer acquisition rather than stopping at survey collection.

## Added
- Survey Builder with sections, question types, options and conditional logic
- Survey Preview
- Campaign + UTM Builder
- QR distribution placeholder
- Source attribution and response workflow
- Market analytics and consumer insights
- 30/90-Day Growth Strategy Builder
- Report workflow
- Responsive public/admin experience

## Core customer-acquisition flow
Research → Segment → Position → Test → Capture interested consumers → Retarget/convert → Launch → Measure → Optimise.

## Important
Static/demo only. No real database, authentication, social APIs, WhatsApp API, live QR generator, AI API or real PDF/PPT export is connected yet.
