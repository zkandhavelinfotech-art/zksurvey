# ZKSurvey v2B.1 — Survey Builder Release

Status: Complete Static Product Prototype enhancement.

## Core change
The Survey Builder is now explicitly industry-agnostic. Milro Dishwash is the first real customer/sample template.

## Workflow
1. Survey Details
2. Sections
3. Questions
4. Answer Options
5. Conditional Logic
6. Preview
7. Publish

## Generic fields
Survey title, survey type, industry, customer/organisation, product/service, description, language, completion time, lead capture and thank-you message.

## Reusable capabilities
- Multiple question types
- Answer option management
- Conditional rules
- Desktop/mobile preview
- Publish validation
- Public survey URL
- Campaign/UTM distribution
- Templates

## First customer
Milro Dishwash — Pre-Launch Consumer Research.

## Still static
No production database, authentication, real QR generation, APIs, AI, exports or persistent publishing yet.
